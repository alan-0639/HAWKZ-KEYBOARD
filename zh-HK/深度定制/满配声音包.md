# 滿配內部填充與聲學組件全解析

> **核心要點**：填充物的終極目的是 **"淨化"與"塑造"聲音**。它們透過吸收不必要的振動和雜音，並精細調整振動的傳遞特性，讓軸體本身產生的乾淨、悅耳的基礎聲音得以清晰地展現，並朝著你喜愛的音色方向演變，從而極大地提升打字的聽覺體驗。
## 核心組件比較表

| 零件名稱 | 位置 | 主要作用 | 常見材質與特性 |
| :--- | :--- | :--- | :--- |
| **軸上墊** | 鍵帽與軸體上蓋之間 | 1. **消除鍵帽雜音**：填滿鍵帽與軸心柱之間的空隙，消除晃動聲。 <br>2. **微調觸感**：使觸底感覺略微更柔和。 | 薄片狀的Poron、矽膠或鐵氟龍，硬度較高，對聲音影響較小。 |
| **夾心棉** | 定位板與PCB板之間 | 1. **消除空腔音**：吸收定位板與PCB之間空腔的振動與迴聲。 <br>2. **統一聲音**：使各位置按鍵聲音一致。 <br>3. **過濾高頻噪音**：讓音色更純粹、更沉悶。 | **PORON**：慢回彈，壽命長，效果最佳。 <br>**IXPE**：性價比高，效果良好。 <br>**矽膠**：重量大，吸音效果好，能增重。 |
| **軸下墊** | PCB與軸體之間 | 1. **消除軸體雜音**：吸收軸體內部金屬彈片音和觸底撞擊PCB的高頻噪音（"叮"聲）。 <br>2. **塑造核心音色**：是打造"Hifi"音的關鍵。 <br>3. **軟化觸底**：使觸底感更"肉"。 | **PORON/IXPE**：能極致地消除雜音，讓軸體聲音更乾淨、集中。 |
| **聲優膜** | 貼附於軸下墊和夾心棉之間 | 1. **進一步提純音色**：作為軸下墊的補充，通過不同材質或厚度，**微調**觸底音的音色和頻率，使其更沉悶或更清脆。 <br>2. **改變觸底硬度**：提供比軸下墊更細微的觸底手感變化。 | **PE** |
| **軸座棉** | PCB底部，覆蓋在軸座之上 | **補充吸音**：從底部吸收透過PCB的殘餘振動和特定頻率的噪音。 | 較薄的PORON或IXPE。注意可能會影響軸座安裝。 |
| **聲優背膜** | 貼附於軸座棉與底棉之間 | 1. **消除PCB板顫**：抑制PCB本身因振動產生的細微"嗡"聲。 <br>2. **補充高頻吸收**：從背面進一步過濾通過PCB孔的殘餘高頻噪音。 <br>3. **改變PCB振動特性**：使PCB整體更"硬"，從而影響傳遞到底棉的振動頻率。 | **PE** |
| **底棉** | 鍵盤PE外殼底部，PCB之下 | 1. **消除最大空腔音**：填充PCB與底殼間的巨大空腔，消除低沉、空洞的迴響。 <br>2. **增加穩重感**：使鍵盤敲擊時更紮實。 | **PORON**：效果最好，壽命長。 <br>**消音棉/EVA**：成本低，但可能老化。 <br>**矽膠**：效果極佳，能大幅增重，需客製化。 |
## 詳細解讀與系統層級影響

### 1. 作用層級與聲音包概念

可以將這些組件理解為一個協同工作的 **"聲音包"** 或 **"消音系統"**：

- **基礎淨化層（消除結構噪音）**：**底棉** 和 **夾心棉**。它們負責處理因鍵盤物理結構產生的**空腔音**和**迴聲**，解決了聲音"塑膠感"和"空洞感"的基礎問題。
- **核心塑造層（消除聲源噪音）**：**軸下墊** 和 **聲優膜**。它們直接作用於聲音的源頭－軸體，負責消除軸體自身的**金屬雜音**，並透過材質和厚度來**主動塑造**核心的按鍵音色，是"麻將音"、"石子音"的靈魂所在。
- **微調最佳化層（精細抑振）**：**聲優背膜**、**軸座棉** 和 **軸上墊**。它們對整體體驗進行精細調整，解決PCB板振、軸座雜音和鍵帽晃動等細節問題。


### 2. 重要注意事項

- **過猶不及**：填充過厚或過硬的棉會**增加鍵盤內部的壓力**，可能導致PCB彎曲、軸體引腳接觸不良、甚至使Gasket結構的"軟彈"手感消失。務必選擇合適厚度的填充物。
- **從上到下順序**：通常的安裝順序是：**軸上墊 → 定位板 → 夾心棉 → 聲優膜 → 軸下墊 → PCB電路板 → 軸座棉 → 聲優背膜 → 底棉**。
- **聲音是系統工程**：填充物只是"淨化"與"塑造"聲音，而鍵盤的最終音色是由 **軸體（核心聲源） + 定位板（調音板） + 填充物（消音系統） + 鍵帽（共鳴腔） + 結構（傳播路徑）** 共同決定的。
